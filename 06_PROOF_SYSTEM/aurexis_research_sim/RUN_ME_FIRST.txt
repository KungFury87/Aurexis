Aurexis Research Simulation Suite v0.6 - start here

** Engine-semantics proof system. **

Aurexis Core = Engine / Codec / Standard.
Aurexis E/D = Client / Wrapper / Runtime.

The suite is NOT "simulate everything" or "generate fake camera wins."
It is an Engine-semantics proof system organized around seven proof
categories.

Requires Python 3.10+. The delivered checkback zip expands to a
folder named Aurexis_Research_Sim_v0_6/.

1. Install:
     pip install -r requirements.txt

2. Launch UI:
     run.bat / ./run.sh
     python -m streamlit run app.py

3. Headless smoke (ends with v0.6 Engine-semantics proof index):
     run_smoke.bat
     python -m aurexis_sim.smoke

4. Top-level v0.6 Engine-semantics outputs:
     python -m aurexis_sim.proof_index
        - master Engine-semantics index across all 7 proof categories
     python -m aurexis_sim.proof_taxonomy
        - 7-category registry + per-report category mapping
     python -m aurexis_sim.confidence
        - per-family TRUST/HOLD/DOWNGRADE/REJECT/NEED_MORE_EVIDENCE
     python -m aurexis_sim.semantic_stability
